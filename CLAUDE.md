The working agreement for this repository is in **[AGENTS.md](AGENTS.md)**. Read it before making
changes — invariants, definition of done, and what needs a human's approval all live there.

This file exists because tools disagree about the filename. Claude Code reads `CLAUDE.md`; Codex and
Cursor read `AGENTS.md`; Hermes reads both at a project root, but only the first match it finds in a
subdirectory. One file with the rules and one pointer to it beats two copies that drift apart.
